# Lockstock - Backend

Web-app che simula una borsa (paper trading, senza denaro reale):
- mercato con orari di apertura e chiusura configurabili (gli ordini vengono rifiutati a mercato chiuso);
- prezzi dei titoli che variano nel tempo;
- ordini di acquisto e vendita e portafoglio virtuale per ogni utente;
- ruoli utente e amministratore.

## Tecnologie

Backend con Spring Boot (Spring Data JPA e MySQL), esposto tramite servizi REST
Frontend in Angular (successivamente nel repo: lockstock-frontend)
